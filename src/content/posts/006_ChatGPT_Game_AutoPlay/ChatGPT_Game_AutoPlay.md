**ChatGPT Game Autoplay**：在 ChatGPT 生成图片时自动玩贪吃蛇。它能认出棋盘、蛇头、食物，三种策略都能跑，面板上实时显示决策依据和路线。

装好之后，启动自动游玩开关，插件能自动帮你玩贪吃蛇。当然本扩展也做了一个油猴脚本的版本，安装后也能自动玩。

![扩展在真实出图页面上的样子](screenshot.png)

* 左边是它正在玩的游戏，右边是实时面板。

* 蓝色虚线是它接下来打算走的路线。

## 三种策略

弹窗里可以随时换，换了立刻生效。

| 策略 | 适合什么情况 |
| --- | --- |
| **安全寻路（BFS）** | 默认，日常首选。先找吃食物的最短路，但只有吃完之后蛇尾还够得着才走，否则挑空间最大的方向。 |
| **空间优先（Flood）** | 棋盘挤的时候用。哪个方向能走到的格子多就往哪走，然后才考虑食物。 |
| **哈密顿环（Cycle）** | 沿着固定环线绕棋盘走，行数是偶数就基本死不了。慢一点，胜在稳。 |

拿不定主意就用默认那个；蛇身越来越长、棋盘开始拥挤的时候，换第二个；想稳到几乎不会输，换第三个。

三种策略都懂这块棋盘的两条怪规则。棋盘四边环绕、没有墙，从左边走出去会从右边回来，规划里算得进去，不会贴着边缘突然撞墙；另外尾巴那一格其实可以走，蛇往前挪的时候尾巴同时让开，所以它敢贴着尾巴走，蛇快铺满棋盘也不会把自己堵死。

游戏还没真正开始的时候，棋盘里会有页面自己的背景动画，它能把这个和真游戏分开，那种时候一下都不按。

## 怎么装

**Chrome、Edge 等 Chromium 浏览器**：打开扩展页（`chrome://extensions`，Edge 是 `edge://extensions`）→ 打开开发者模式 → 点「加载已解压的扩展程序」→ 选文件夹 → 刷新 ChatGPT 页面。

**Firefox 128 或更高版本**：打开 `about:debugging#/runtime/this-firefox` → 「临时载入附加组件…」→ 选构建里的 `manifest.json`。这个是临时载入，浏览器重启后要重新载一次。

**油猴 / Violentmonkey**：从最新 release 安装 `snake-autoplay.user.js`，带 `@updateURL`，之后的版本会自动更新。这个版本没有工具栏弹窗，策略和语言选择放在页面面板里。

## 说明

- 支持五种界面语言：English、中文、Français、Русский、Español。
- 识别是尽力而为的。正常情况下状态是从页面里精确读到的；万一 ChatGPT 改版导致读不到，它会退回去辨认画布画面，棋盘、蛇头、食物依然认得出来，蛇很长的时候坐标会有点近似，面板上的「来源」那一行会告诉你它走的是哪条路。
- 一切都在你自己的浏览器里完成，它只读你已经打开的那个 ChatGPT 页面，不往外发任何数据。
